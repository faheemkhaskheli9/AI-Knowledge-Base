# Gaussian mixture models and the EM algorithm

## Summary
A Gaussian mixture model (GMM) says the data was generated by `K` Gaussian blobs, each with its own mean, covariance (shape) and weight. Fitting one gives soft clustering (each point gets a probability per cluster), a full density estimate (`score_samples` = log-likelihood, useful for anomaly detection) and a principled way to pick `K` (BIC). It is fitted with Expectation-Maximisation (EM), the general recipe for any model with hidden variables: guess, assign responsibilities, re-estimate, repeat.

## Key concepts
- **Model.** `p(x) = Σ_k π_k · N(x | μ_k, Σ_k)`. Weights `π_k` sum to 1. The cluster each point came from is a hidden (latent) variable.
- **EM algorithm.**
  - **E-step:** compute responsibilities `r_ik = P(cluster k | x_i)` with the current parameters.
  - **M-step:** re-estimate `π_k`, `μ_k`, `Σ_k` as responsibility-weighted averages.
  - Each iteration never lowers the likelihood; it converges to a *local* optimum, so use several restarts (`n_init`).
- **k-means is a special case**: hard assignments + equal spherical covariances. GMM adds soft assignments and per-cluster shape and size.
- **Covariance type** (`covariance_type`): `full` (any ellipse; most parameters), `tied` (all clusters share one shape), `diag` (axis-aligned ellipses; good in higher dimensions), `spherical` (k-means-like).
- **Choosing K.** `bic(X)` / `aic(X)`: lower is better; BIC penalises parameters more and is the usual choice. `BayesianGaussianMixture` with a Dirichlet-process prior shrinks unused components' weights toward zero automatically.
- **Density uses.** `score_samples(X)` gives per-point log-density: low values = anomalies. `sample(n)` generates synthetic points.
- **EM beyond GMMs.** The same E/M loop fits HMMs (Baum-Welch, see [[hidden-markov-models-and-kalman-filters]]), mixtures of other distributions, missing-data imputation and latent topic models.

## When to use / scenarios
- Customer or patient segmentation where segments overlap and you want "70% segment A, 30% segment B", not a hard label.
- Anomaly detection on a few continuous features (transaction amount + time, sensor temperature + vibration): fit a GMM on normal data, flag low `score_samples`.
- Speaker or background modelling in classic audio pipelines; colour-based image segmentation.
- Clusters are elongated, differently sized or differently dense (k-means assumes round, equal clusters).
- NOT for high-dimensional raw data (images, text): reduce dimensions first ([[dimensionality-reduction]]) or use embeddings. NOT for non-elliptical shapes like rings or arbitrary blobs: use DBSCAN/HDBSCAN ([[clustering]]).

Pick K by BIC, read soft memberships, flag anomalies by density, and a 20-line EM in NumPy that shows what `fit` does:
```python
import numpy as np
from sklearn.mixture import GaussianMixture
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(0)
X = np.vstack([
    rng.multivariate_normal([0, 0], [[1.0, 0.8], [0.8, 1.0]], 300),   # elongated
    rng.multivariate_normal([4, 0], [[0.3, 0.0], [0.0, 0.3]], 200),   # small, tight
    rng.multivariate_normal([2, 4], [[1.5, 0.0], [0.0, 0.5]], 250),
])
X = StandardScaler().fit_transform(X)

# 1. Choose K and covariance type by BIC.
best = min(
    (GaussianMixture(k, covariance_type=c, n_init=5, random_state=0).fit(X)
     for k in range(1, 7) for c in ("full", "diag", "spherical")),
    key=lambda g: g.bic(X),
)
print("chosen K:", best.n_components, "covariance:", best.covariance_type)

# 2. Soft memberships.
probs = best.predict_proba(X[:3])
print("membership probabilities:\n", probs.round(3))

# 3. Density-based anomaly flag: bottom 1% log-likelihood on (assumed normal) training data.
threshold = np.percentile(best.score_samples(X), 1)
new = np.array([[0.0, 0.0], [8.0, -8.0]])
print("anomaly:", best.score_samples(new) < threshold)

# 4. EM from scratch (1-D, 2 components) to see the E and M steps.
def norm_pdf(x, mu, var):
    return np.exp(-(x - mu) ** 2 / (2 * var)) / np.sqrt(2 * np.pi * var)

x = np.concatenate([rng.normal(-2, 0.5, 400), rng.normal(3, 1.0, 600)])
pi, mu, var = np.array([0.5, 0.5]), np.array([-1.0, 1.0]), np.array([1.0, 1.0])
for _ in range(100):
    dens = pi * norm_pdf(x[:, None], mu, var)              # E-step: (n, K)
    r = dens / dens.sum(1, keepdims=True)                  # responsibilities
    nk = r.sum(0)                                          # M-step
    pi, mu = nk / len(x), (r * x[:, None]).sum(0) / nk
    var = (r * (x[:, None] - mu) ** 2).sum(0) / nk
print("EM weights", pi.round(2), "means", mu.round(2), "stds", np.sqrt(var).round(2))
```
The scratch EM should recover weights ≈ [0.4, 0.6], means ≈ [-2, 3] and stds ≈ [0.5, 1.0].

## Choosing / trade-offs
- **GMM vs k-means.** k-means is faster and simpler for round, similar-sized clusters and very large data; GMM when you need probabilities, densities or elliptical clusters of different sizes.
- **GMM vs DBSCAN/HDBSCAN.** Density-based methods find arbitrary shapes and label noise points, but give no generative density or soft memberships.
- **`full` vs `diag` covariance.** `full` captures correlations but has O(K·d²) parameters and overfits with many features or few points per cluster; `diag` scales to more dimensions.
- **BIC vs Bayesian GMM.** BIC needs a sweep over K; `BayesianGaussianMixture` fits once with an upper bound on K and prunes, at the cost of prior hyperparameters (`weight_concentration_prior`).
- **GMM vs other density estimators for anomalies.** GMM is compact and fast to score; Isolation Forest handles more dimensions and mixed feature types ([[anomaly-detection]]); kernel density estimation is non-parametric but slow on large data.

## Gotchas
- Not scaling features first: one large-scale feature dominates the covariance and the clusters.
- Single runs land in bad local optima; set `n_init` ≥ 3-10.
- A component collapsing onto one or a few points gives a near-singular covariance and huge likelihood; `reg_covar` (default 1e-6) guards this, raise it if you see warnings or degenerate clusters.
- BIC on a single `random_state` can be noisy; compare a few seeds before trusting a small BIC difference.
- Cluster indices are arbitrary and change between fits; map them by mean, not by index, when comparing runs.
- `predict_proba` near 1.0 for every point does not mean the clusters are real; GMM always finds K groups. Check with domain knowledge or stability across resamples.
- EM converges to a local optimum and does not report "wrong K"; that is BIC's job.
